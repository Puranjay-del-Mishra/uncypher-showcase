# UnCypher

Information discovery through clustering and vector retrieval.

## About the project

UnCypher explores how information can be organized around a person's interests and context. The project brings together clustering, retrieval and backend services in an information-discovery pipeline.

## Project work

Clustering groups related candidates, while retrieval supports finding information relevant to a query or context. Python and Java services connect those processing steps to an application, with Spring Boot supporting the backend.

## Architecture

- **HDBSCAN** groups related candidates into clusters.
- **Vector retrieval** supports finding relevant information within the pipeline.
- **Python, Java and Spring Boot** provide processing and backend services.
